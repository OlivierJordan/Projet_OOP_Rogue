## Prérequis Système
- **Java JDK** : 21 ou supérieur
- **JavaFX** : Géré via Maven
- **Outil de Build** : Maven

## Instructions d'exécution (IDE - IntelliJ IDEA recommandé)
1. Ouvrez/Importez le dossier racine du projet dans votre IDE.
2. Laissez Maven télécharger les dépendances (synchronisation du fichier `pom.xml`).
3. Naviguez vers `src/main/java/com/example/projet_oop_rogue/core/` (ou l'emplacement de votre lanceur).
4. Exécutez la classe principale `HelloApplication.java` (ou la classe `Launcher.java` si vous avez séparé le point d'entrée pour contourner les modules JavaFX).

## Notes sur la persistance (Scores)
Le système de leaderboard lit et écrit dans un fichier nommé `leaderboard.csv`. Ce fichier sera créé automatiquement à la racine de votre dossier d'exécution à la fin de la première partie s'il n'existe pas déjà.
